## Risks & Deviations

- **chokidar v4 is ESM-only.** Project already uses `"type": "module"`. No change needed. If vitest config tests the watcher, the test must use `await import()` style (not require).
- **HTTP server cleanup in cli tests.** Spawning `ctx serve` and killing the child with SIGTERM may leave a port in TIME_WAIT for ~30s. The serve test uses port 17331 (high range, low conflict risk). On EADDRINUSE the test is expected to fail; document `CTX_TEST_SKIP_SERVE=1` for local dev.
- **Port 7331 in CI.** A real CI runner may already bind 7331. The serve test uses 17331 to avoid contention. The `ctx serve` default (7331) is unchanged per D-15.
- **Smoke test runs last.** Alphabetical: `smoke > repair > retrieve > graph > health > fingerprint > cache`. vitest order is by file path. Confirmed.
- **Coverage threshold (70%) on new modules.** `src/watcher.ts`, `src/serve.ts`, `src/adapter-claude-code.ts`, extended `src/cli.ts`. If coverage drops below 70%, add tests in Task 4 (cli) or 3 (watcher/adapter) — do not lower the threshold (D-19).
- **buildGraph `force` option.** The `--rebuild` flag requires adding a `{ force?: boolean }` option to `buildGraph`. The extension is small and the option is read at one site (the hash-skip check). Risk: if `buildGraph` is called elsewhere with a `force` key spread, it propagates; do NOT spread the options object.
- **Watcher test timing.** The deferred-event test uses a 100ms debounce and a 2s timeout. On a heavily loaded CI machine the file event may take >100ms; the test allows 2s to absorb that.
- **Adapter dbPath default = `.ctx.db`.** Adapter test 3 (default dbPath) is `it.skipIf(!existsSync(.ctx.db))` — in CI after the first test run, .ctx.db exists. Locally before any build, the test is skipped. Acceptable.
